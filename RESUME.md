# Resume Entry

**DevOpsFlow AI – Intelligent Task, Deployment and API Monitoring Platform**  
Java, Spring Boot, Spring Security, JWT, MySQL, React, Docker, REST APIs, Swagger

- Developed an enterprise-style DevOps workflow platform for task management, deployment tracking, API monitoring, alerting and analytics.
- Implemented secure JWT authentication, role-ready users, BCrypt password encryption, REST APIs, JPA/Hibernate persistence and global exception handling.
- Built deployment risk scoring, API uptime tracking, response latency logs, alert history, audit logs and dashboard analytics.
- Created a React dashboard with Kanban-style task lanes, deployment timeline, monitoring metrics and chart-based operational insights.
- Added Docker Compose support for MySQL, backend and frontend services plus Swagger documentation for API testing.

## Short Project Pitch

I built DevOpsFlow AI to solve a real software delivery problem: teams often track tasks, deployments and API health in separate tools. My project brings these workflows into one platform and adds rule-based AI insights such as deployment risk scoring, unstable API alerts and delivery recommendations.
